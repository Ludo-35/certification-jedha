# 🛒 Walmart — Prédiction des ventes hebdomadaires

**Bloc de certification :** B3 — Analyse prédictive de données structurées par intelligence artificielle

## 🎯 Objectif

Prédire les **ventes hebdomadaires** de magasins Walmart à partir de données structurées (historique de ventes, facteurs économiques et calendaires), dans une démarche d'apprentissage automatique supervisé.

## 🛠️ Approche

- **Analyse exploratoire (EDA)** des données de ventes et des variables explicatives
- **Modélisation par régression** :
  - Régression linéaire (baseline)
  - Régularisation **Ridge**
  - Régularisation **Lasso**
- Comparaison des performances entre les différentes approches de régularisation

## 🛠️ Stack technique

- **Traitement & analyse** : Pandas, NumPy
- **Modélisation** : Scikit-learn (LinearRegression, Ridge, Lasso)
- **Visualisation** : Matplotlib / Seaborn

## 📬 Livrables

- Notebook complet : EDA, modélisation, évaluation des modèles
- Mémoire associé au projet
