# Getaround — Dashboard Analyse des Retards

Tableau de bord Streamlit permettant au chef de produit d'explorer l'impact
d'un délai minimum entre deux locations (seuil + portée) sur les retards
et les conflits de restitution.

## Installation locale

```bash
pip install -r requirements.txt
streamlit run app.py
```
