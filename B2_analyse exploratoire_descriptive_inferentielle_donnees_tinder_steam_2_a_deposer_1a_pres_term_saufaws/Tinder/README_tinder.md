# 💘 Speed Dating — Analyse pour Tinder

**Bloc de certification :** B2 — Analyse exploratoire, descriptive et inférentielle de données

## 🎯 Contexte

Cas d'usage fictif pour **Tinder** : comprendre les dynamiques d'attirance et de choix lors de sessions de speed dating, à partir d'un dataset académique collecté entre **2002 et 2004**.

## 🎯 Objectif

Réaliser une analyse statistique descriptive et inférentielle du dataset Speed Dating :
- Statistiques descriptives sur les participants et leurs préférences
- Étude des corrélations entre critères déclarés et choix réels ("match")
- Visualisations pour illustrer les tendances observées
- Interprétation des résultats dans une perspective produit (implications pour une app de dating)

## 🛠️ Approche

Analyse exploratoire complète du dataset (nettoyage, statistiques descriptives, corrélations) suivie d'une interprétation des résultats au regard des objectifs business fictifs de Tinder.

## 🛠️ Stack technique

- **Traitement & analyse** : Pandas, NumPy
- **Statistiques** : corrélations, tests statistiques
- **Visualisation** : Matplotlib / Seaborn

## 📬 Livrables

- Notebook complet : statistiques, visualisations et interprétations
- Présentation orale (~5 minutes) devant un jury
